# 명언 — 라이선스 기록

## 글
- 실린 원문은 모두 저작권 보호기간이 끝난 글(1962년 이전 사망자의 글, 고전)이다. 원문 대조에 쓴 전자 텍스트: Project Gutenberg, 위키문헌(중국어·한국어), Sefaria, The Latin Library — 각 명언의 근거 링크 참고.
- 우리말 번역·해설·활용 예는 재미랩이 직접 썼다. 출판된 한국어 번역과 위키인용집 번역 문장은 쓰지 않았다.
- 『명상록』 원문 칸은 George Long 영역(1862, 퍼블릭 도메인).
