# 식구궁합 — 출처와 계산 근거

식구궁합은 전통 명리(命理) 이론의 표준 표를 그대로 옮겨 재미로 보여 주는 도구입니다. 과학적 예측이 아닙니다.

## 1. 사주 기둥 (년·월·일·시주)

- 계산은 `../roots/js/saju.js`(근본 테스트 엔진)에 위임합니다. `js/saju-adapter.js`가 그 API를 이 앱의 인터페이스
  `computeSaju(y, m, d, hour, minute, { lunar, leap }) → { year, month, day, hour }`로 맞춥니다.
- roots 엔진(v2)의 기준: 입춘·12절의 정확한 절입 시각(태양 겉보기 황경, VSOP87 절삭식), 역사적 한국 표준시·서머타임(IANA tz `Asia/Seoul`),
  동경 127.5° 지방시 보정, 오호둔(월간)·오서둔(시간), 율리우스 적일 기반 일진(2000-01-01 = 戊午). 음력은 한국천문연구원 음력(1900–2050).
- roots 엔진을 불러오지 못하면 평균 절입일 근사로 대체하며, 바닥글에 그 사실을 표시합니다.

## 2. 오행 상생·상극

- 상생(相生): 木生火, 火生土, 土生金, 金生水, 水生木
- 상극(相剋): 木剋土, 土剋水, 水剋火, 火剋金, 金剋木
- 천간 오행: 甲乙 木, 丙丁 火, 戊己 土, 庚辛 金, 壬癸 水 / 지지 오행: 寅卯 木, 巳午 火, 辰戌丑未 土, 申酉 金, 亥子 水
- 출처: 오행 생극은 『연해자평』·『삼명통회』 등 명리 고전과 일반 명리 입문서에 공통된 표준 내용입니다.

## 3. 천간합 (天干五合)

甲己合土 · 乙庚合金 · 丙辛合水 · 丁壬合木 · 戊癸合火 — 명리 고전의 천간합(化氣) 표준 표.

## 4. 지지 관계 표 (地支 合·沖·刑·破·害)

| 관계 | 짝 | 비고 |
|---|---|---|
| 육합(六合) | 子丑(土) · 寅亥(木) · 卯戌(火) · 辰酉(金) · 巳申(水) · 午未(火/土) | 午未합의 화(化)오행은 문헌마다 火 또는 土 |
| 삼합(三合) | 申子辰 水局 · 亥卯未 木局 · 寅午戌 火局 · 巳酉丑 金局 | 두 글자만 있으면 반합(半合)으로 계산 |
| 육충(六沖) | 子午 · 丑未 · 寅申 · 卯酉 · 辰戌 · 巳亥 | 서로 정반대(6칸) |
| 형(刑) | 寅巳申 무은지형(無恩之刑) · 丑戌未 지세지형(持勢之刑) · 子卯 무례지형(無禮之刑) · 辰辰 午午 酉酉 亥亥 자형(自刑) | 삼형은 짝 단위(寅巳, 巳申, 申寅 / 丑戌, 戌未, 未丑)로 셈 |
| 육파(六破) | 子酉 · 丑辰 · 寅亥 · 卯午 · 巳申 · 未戌 | |
| 육해(六害·穿) | 子未 · 丑午 · 寅巳 · 卯辰 · 申亥 · 酉戌 | |

- 출처: 『삼명통회(三命通會)』·『연해자평(淵海子平)』의 지지 합·충·형·파·해 논의에서 전해지는 표준 표로, 현대 명리 입문서와 위키백과(한국어·중국어) 「지지(地支)」 항목에 실린 표와 같은 내용입니다. 표 자체는 문헌 간 이견이 거의 없고, 이견이 있는 부분(午未합의 오행)은 위에 적었습니다.
- 겹침: 한 쌍이 여러 관계에 동시에 해당할 수 있습니다(巳申 = 합·형·파, 寅亥 = 합·파, 寅巳 = 형·해, 寅申·丑未 = 충·형). 식구궁합은 해당되는 항목을 모두 더합니다.
- 단위 테스트: `tests/relations.test.mjs` (`node --test family/tests/relations.test.mjs`).

## 5. 띠

띠 = 년주 지지(子 쥐 … 亥 돼지). 명리 관례대로 **입춘** 기준이며, 설날 기준으로 띠를 세는 민간 관습과 1~2월생은 다를 수 있습니다.
띠 궁합은 위 지지 관계 표를 년지끼리 적용한 것입니다(전통 띠 궁합의 "삼합띠·육합띠·원진/충띠" 중 원진은 넣지 않았습니다).

## 6. 이 앱이 정한 것 (전통 표가 아닌 부분)

다음은 전통 문헌의 정해진 값이 아니라 식구궁합이 투명하게 정한 규칙이며, 화면의 "어떻게 계산했나요?"에 그대로 표시됩니다.

- 점수 가중치 (`js/relations.js`의 `W`): 기본 50점, 일간 상생 +14 / 같은 오행 +6 / 상극 −12, 천간합 +8,
  일지 육합 +10 · 삼합 +7 · 같은 글자 +2 · 충 −10 · 형 −7 · 자형 −4 · 파 −4 · 해 −5,
  띠 육합 +6 · 삼합 +4 · 같은 띠 +2 · 충 −6 · 형 −4 · 자형 −2 · 파 −2 · 해 −3, 5~98점으로 제한.
- 오행 밸런스: 천간·지지 표면 글자만 셈(지장간 제외). 10% 미만이면 "부족".
- 가족 역할: 통관(通關) 개념(상극 사이를 생으로 잇는 오행)으로 중재자, 극하는 수로 추진자, 생하는 수로 분위기메이커, 생 받는 수로 "사랑받는 사람".
- 부족한 기운의 연상(계절·색·방위)은 오행 배속표(오행과 계절·방위·오방색을 잇는 전통 배속)에서 가져왔고, "채워 보기" 팁은 재미용 제안입니다.
