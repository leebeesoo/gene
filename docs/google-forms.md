# 구글 폼 만들기 안내

사장님이 직접 만드실 폼은 두 개입니다. 만든 뒤 아래 "알려주실 것"만 전해 주시면 사이트에 연결합니다.

## 폼 1. 맛남의 광장 연결 신청

구글 폼 새로 만들기 → 제목 「맛남의 광장 연결 신청」.
설정 → 응답 → 「이메일 주소 수집」 끄기, 「응답 1회로 제한」 끄기(로그인 강제됨).
응답 탭 → 스프레드시트 연결(새 시트).

### 섹션 1 (공통)
- **나는** — 객관식, 필수. 선택지 문구를 아래와 글자 하나까지 똑같이(사이트 `market/js/config.js`의 ROLE_LABELS로 미리 채웁니다).
  - `농가·어가(남는 물량 있음)` → 섹션 2로 이동
  - `받을 곳(식당·가공업체·급식)` → 섹션 3으로 이동
  - `제보` → 섹션 4로 이동
  - `구출 원정대` → 섹션 5로 이동
- **지역(시도)** — 드롭다운, 필수: 서울 부산 대구 인천 광주 대전 울산 세종 경기 강원 충북 충남 전북 전남 경북 경남 제주
- **시군구** — 단답형, 선택

### 섹션 2 (농가·어가: 남는 물량 연결) → 다음은 섹션 6
- 품목 — 단답형, 필수
- 예상 물량 — 단답형, 필수 (응답 확인: 숫자)
- 단위 — 객관식: kg / 박스 / 톤
- 출하 가능 시기 — 단답형, 선택
- 희망 가격(kg당) — 단답형, 선택
- 확인 — 체크박스, 필수: 「이 물량은 출하정지·산지폐기 보상 약정 물량이 아닙니다」
- 확인 — 체크박스, 필수: 「맛남의 광장은 소개만 하며 거래 당사자가 아니고, 상대가 동의할 때 연락처가 전달됨을 이해합니다」

### 섹션 3 (받을 곳: 식당·가공업체·급식) → 섹션 6
- 업종 — 객관식, 필수: 식당 / 가공업체 / 유통 / 단체급식 / 개인 / 기타
- 관심 품목 — 단답형, 필수
- 한 달 필요량 — 단답형, 필수
- 희망 지역 — 단답형, 필수
- 희망 가격 — 단답형, 선택

### 섹션 4 (제보) → 섹션 6
- 품목 — 단답형, 필수
- 예상 물량 — 단답형, 선택
- 갈아엎기·폐기 예정일 — 날짜, 선택
- 어떻게 알게 되셨나요(직접 봄, 뉴스 링크 등) — 장문형, 선택
- 사진 링크 — 단답형, 선택. 설명: 「사진은 링크로 붙이거나 이메일로 보내 주세요」
  (파일 업로드 질문은 넣지 마세요. 넣으면 응답자가 구글 로그인을 해야 합니다.)

### 섹션 5 (구출 원정대) → 섹션 6
- 인원 — 단답형, 필수 (숫자)
- 갈 수 있는 지역 — 단답형, 필수
- 가능한 요일 — 체크박스, 필수: 월~일
- 차량 — 객관식, 선택: 있음 / 없음

### 섹션 6 (공통 마무리)
- 연락처(휴대폰 또는 이메일) — 단답형, 필수
- 이름 또는 닉네임 — 단답형, 선택
- 개인정보 동의 — 체크박스, 필수. 질문 설명에 아래 문구:

> [개인정보 수집·이용 동의]
> 1) 수집 항목: 연락처(휴대전화 또는 이메일), 이름/닉네임(선택), 지역
> 2) 수집·이용 목적: 지역별 연결(농가와 받을 곳 소개), 제보 확인 연락
> 3) 보유·이용 기간: 수집일로부터 1년 또는 삭제 요청 시까지 보유 후 지체 없이 파기
> 4) 동의를 거부할 권리가 있으며, 거부 시 알림·연결을 받을 수 없습니다(지도·계산기 이용은 제한 없음).
>
> ☐ 위 내용에 동의합니다

### 대기 인원 표시용 집계 탭 (응답 시트에서)
1. 응답 시트에 새 탭 「집계」를 만듭니다.
2. A1 `지역`, B1 `농가`, C1 `구매자`, D1 `원정대`, E1 `제보`. A2부터 17개 시도를 적습니다.
3. (사이트 표시용 열 이름: 지역,농가,구매자,원정대,제보) B2에 `=COUNTIFS('설문지 응답 시트1'!$C:$C,$A2,'설문지 응답 시트1'!$B:$B,"농가·어가(남는 물량 있음)")` (B열=「나는」, C열=「지역」 기준. 실제 열에 맞게 고칩니다). C·D·E는 선택지 문구만 바꿔 복사.
4. 파일 → 공유 → 웹에 게시 → **「집계」 탭만** 선택 → CSV → 게시. 나온 주소를 알려주세요.
5. **응답 탭은 절대 게시하지 마세요.** 연락처가 공개됩니다.

### 알려주실 것
- 폼 주소(…/viewform)
- 미리 채운 링크: 폼 ⋮ → 「미리 채워진 링크 받기」에서 나는/지역/시군구/품목에 아무 값이나 넣고 링크 복사 → 그 링크 그대로
- 집계 탭 CSV 주소

## 사이트에 넣는 곳
받은 값은 `market/js/config.js`의 `FORM_URL`, `FORM_ENTRY`(role·sido·sigungu·item 번호), `COUNTS_CSV_URL`에 들어갑니다. 알려주시면 제가 넣습니다.

## 폼 2. 제철식당 제보 (문 닫았어요 · 이 메뉴 없어요)
- 제보 종류 — 객관식, 필수: `문 닫았어요` / `이 메뉴 없어요` / `기타`
- 식당 이름 — 단답형, 필수
- 주소 — 단답형, 선택
- 음식 — 단답형, 선택
- 지역 — 단답형, 선택
- 화면 주소 — 단답형, 선택 (사이트가 자동으로 채웁니다)
- 내용 — 장문형, 선택
- 연락처를 받지 않으면 개인정보 동의 문항은 필요 없습니다(익명 제보 권장).

알려주실 것: 폼 주소와 미리 채운 링크(종류·식당 이름·음식에 아무 값). `sikdang/js/config.js`의 `REPORT_FORM_URL`, `REPORT_FIELDS`에 들어갑니다.
