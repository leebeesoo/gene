## 4. 쉽게 보이고 흥미롭게 보이는 것

1. **공유 링크를 유형 페이지로**: `/roots/type/tkhs/?from=민지` 형태. 카톡 미리보기에 "섬세한 화원 TKHS · MBTI로 치면 INFJ" 유형별 OG 이미지가 뜨고, 받은 사람은 설명을 읽은 뒤 "나도 하기"로 들어옴(16personalities 방식). 초대 비교(`?invite=`)는 쿼리로 유지.
2. **"MBTI로 치면" 다리 놓기**: 유형 페이지 제목에 MBTI를 병기 → "INFJ 조선시대 직업" 검색과 "MBTI 조선시대" 바이럴 둘 다 잡음.
3. **인스타 스토리 1080×1920 카드**: 지금은 가로 카드뿐. 세로 카드에 도장(낙관) + 코드 + "희귀도 4.7%".
4. **매일 바뀌는 훅**: `DAILY`·`todayStrongType`이 이미 있음 → `/roots/today/` "오늘 기운이 센 근본 코드"(날짜·일진 표시). 띠 페이지엔 "오늘의 일진 {갑자}일".
5. **본관 카드**: "김해 김씨 445만 명 중 1명 · 시조 김수로왕(가야)" — 명절 단톡방용. 결과에 "우리 본관 페이지 보기" 링크.
6. **이름 카드**: "서윤 — 2026년 여아 1위, 평균 출생연도 2016년". 이름 페이지마다 OG 이미지(이름 큰 글씨 + 순위 막대).
7. **식구궁합 명절 모드**: 설·추석 2주 전 허브와 띠 페이지 상단에 "가족 궁합판 만들기" 배너(이미 `festival.js` 있음).

## 5. 실행안

생성 방식: `tools/build-seo.mjs`(Node, 의존성 없이 문자열 템플릿)가 `roots/js/data.js`·`facts.js`·`names/js/data.js`·`family/js/relations.js`를 import해 정적 HTML을 만들어 **생성 파일을 커밋**(Cloudflare 빌드 명령 없음 유지). OG PNG는 GitHub Actions에서 `@resvg/resvg-js`로 SVG→PNG, 또는 로컬 Playwright 스크린샷 후 커밋. 각 생성 페이지 = 정적 본문 + 앱으로 가는 CTA + 같은 종류 이웃 페이지 링크 + 브레드크럼 + 공용 푸터·광고.
