## 4. 쉽게 보이고 흥미롭게 보이는 것

- **"이번 주 제철 1개" 훅**: 홈 첫 화면과 OG 이미지를 매주 교체(예: "이번 주는 굴 — 통영 굴구이 12곳"). 매월 1일 `/season/{월}/` 카드가 카톡·인스타 스토리용 1080×1920 이미지로 저장되게(이미 canvas 공유 카드 코드 있음 → 품목 사진으로 교체).
- **가격 짤**: `/market/배추/` "평년보다 −42%, 10kg 4,792원(가락, 11-04)" 큰 숫자 카드 → 김장철 맘카페·지식iN 답변에 그대로 붙일 수 있게 이미지+링크.
- **지역 비교 링크**: "전어 — 여수 10곳 vs 보성 6곳 vs 하동 4곳" 같은 재료 페이지가 커뮤니티(더쿠·클리앙 "여수 맛집" 자동완성 확인) 공유에 적합.
- **식당 카드 공유**: "여수 전어구이, 관광 누리집이 고른 집" 문구 + 출처 → 협찬 없는 근거가 재공유 동기.
- 네이버 블로그·카페 시딩은 월 1회 "11월 제철 지도" 글 1편만(과하면 저품질 판정).

## 5. 실행안 + 페이지 문구(바로 쓰는 카피)

공통 규칙: `{ORIGIN}` = Cloudflare 실제 도메인. 모든 페이지 `<link rel="canonical" href="{ORIGIN}/…/">`(끝 슬래시), `og:url` 동일, `og:locale ko_KR`, `twitter:card summary_large_image`, 본문 상단 첫 문단 = 질문에 대한 한 문장 정답 + "기준일·출처". 빌드: `tools/build-pages.mjs`(Node, 의존성 없음)가 JSON을 읽어 `/{서비스}/{…}/index.html`을 생성·커밋(일일 데이터 워크플로 끝에 실행). 생성 HTML은 같은 CSS/JS를 불러 SPA가 이어받고, 기존 해시 주소는 `location.replace`로 새 경로에 넘김. `sitemap.xml`(서비스별 + 이미지 사이트맵), `robots.txt`(Sitemap 줄) 추가 후 네이버 서치어드바이저·구글 서치콘솔 제출.

### 5-3. 이미지 SEO (재료 사진 281장)
- 파일명: 현재 로마자(`jeoneo.webp`) 유지 — 캐시 규칙상 이름 변경 = 교체. 새 파일은 `{로마자}-{특징}.webp`(예 `gul-tongyeong.webp`).
- alt: `{재료}, {한눈에 보이는 모습}` 15~40자. 예 "전어, 은빛 비늘의 손바닥만 한 가을 생선". 같은 사진이 장식이면 `alt=""`. "사진/이미지" 단어 금지.
- `<img width="717" height="540" loading="lazy" decoding="async">`, 첫 화면 1장만 `fetchpriority="high"`.
- ImageObject:
```json
{"@type":"ImageObject","contentUrl":"{ORIGIN}/sikdang/img/ing/{slug}.webp","name":"{재료}","caption":"{alt}","width":717,"height":540,"creditText":"{제작자/출처}","copyrightNotice":"{저작권자}"}
```
  출처·라이선스를 모르면 creditText/license를 넣지 않음. AI 생성 사진이면 IPTC `digitalSourceType: trainedAlgorithmicMedia` 표기.
- 이미지 사이트맵: 각 `/season/{item}/`, `/sikdang/food/{ing}/` URL에 `<image:image><image:loc>` 1장.
