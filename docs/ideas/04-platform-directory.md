한 줄 결론: **하자. 로컬 탭은 그대로(공정위 가맹정보 + 상가정보), 온라인 탭은 「배달앱·쇼핑·중고·숙박·구인구직 같은 플랫폼·앱 카드」 약 45개를 구글 시트로 직접 정리하고, 공정위·개보위 처분과 DART 회사 숫자만 자동으로 붙인다.**

> **공개 시점: 애드센스 승인 뒤** (창업 비용·수수료처럼 돈 판단을 돕는 대량 페이지라서)

# 04. 공공데이터 브랜드 카드 (가칭 「브랜드 돋보기」, `/brand/`) — 최종안

작성 2026-11-13 · 수정 2026-11-13(사장님 정정: 온라인 탭 = 플랫폼·앱) · 조사 전용 문서, 사이트 코드는 고치지 않음
「확인 필요」는 공식 원문을 열어 보지 못했거나 출처끼리 말이 다른 부분이다. 만들기 전에 원문·실제 응답으로 확인한다.

## 1. 최종안 요약

- **무엇**: 공공데이터 + 공식 안내 페이지로 만든 브랜드 카드. 손님과 사장님이 같은 카드를 보고, 「나에게 맞는 것 찾기」 질문으로 좁힌다.
- **두 탭**
  - **로컬**: 매장이 있는 브랜드(주로 프랜차이즈). 공정위 정보공개서 숫자(매장 수, 개점·폐점, 평균 매출, 창업 비용) + 내 동네 매장 수.
  - **온라인**: **플랫폼·앱**(배달앱, 오픈마켓, 중고거래, 숙박·여행, 전문가·프리랜서, 구인구직, 부동산, 간편결제). 손님에게는 「나한테 맞는 앱」, 사장님에게는 「어디에 올릴까, 조건은?」(수수료 구조·정산 주기·공식 안내 링크). 처분 이력·회사 규모는 공공 자료로 붙인다. 별점·후기·순위는 없다.
- **원칙**: 칸마다 「출처 · 기준일(또는 확인일)」. 「최고·최악·추천 1위」 금지. 로고 없이 이름만. 정정 요청 폼. 제휴 링크는 v1에 없음.
- **돈**: 애드센스 + 검색 유입. 로컬은 「OO치킨 창업비용」 같은 브랜드 검색어 수천 개, 온라인은 「배민 수수료」, 「쿠팡이츠 정산일」, 「크몽 수수료」, 「당근 vs 번개장터」 같은 질문형 검색어.
- **비용**: 0원. 로컬은 공공데이터포털 키(`DATA_GO_KR_KEY`), 온라인은 구글 시트 + OpenDART 키(무료) + 국가법령정보 공동활용 키(무료). GitHub Actions가 모아 정적 JSON·페이지로 만든다.

- **확인일 90일 넘으면** 카드에 회색 「확인한 지 오래됨」 표시 + 사장님 할 일 목록에 올림. 180일 넘으면 수수료 칸을 접고 공식 링크만.

## 5. 화면 구성

**첫 화면 `/brand/`**: 검색창 + 탭 [로컬] [온라인 플랫폼] + 「나에게 맞는 것 찾기」 + 분야 바로가기.

**로컬 카드** (`/brand/l/{브랜드관리번호}/`)
- 위: 브랜드명, 업종, 본부, 가맹사업 시작 연도, 「OOOO년 정보공개서 기준 · 수집일」
- 손님 줄: 전국·내 시도·내 동네(추정) 매장 수, 본부 영업 상태
- 창업자 줄: 창업 비용 합계·내역, 평균 매출, 3년 매장 수 그래프, 개점·폐점, 계산한 폐점률(식), 본부 재무, 시정조치(있을 때만)
- 아래: 업종 평균과 나란히, 「비교에 담기」, 정보공개서 원문, 「정보가 틀렸어요」
- 고정 문구: 「공공데이터를 가공해 보여 줍니다. 투자·창업 권유가 아닙니다. 계약 전 정보공개서 원문과 본부·가맹점주 확인이 필요합니다.」

**온라인 플랫폼 카드** (`/brand/p/{영문-슬러그}/`, 예: `/brand/p/baemin/`): 위 4장의 칸을 [손님에게] [사장님에게] 두 덩어리로. 수수료는 문장 요약 + 공식 링크 + 확인일. 처분 이력은 중립 회색 목록.

**분야 페이지** (`/brand/p/c/{분야}/`, 9개): 그 분야 플랫폼 표(같은 칸 나란히, 정렬은 가나다순 고정), 공식 조사 한 줄, 「손님이 고를 때 볼 것」, 「사장님이 입점 전 볼 것」(예: 배달앱 = 중개수수료·배달비·결제수수료·광고비가 따로임).

**나에게 맞는 것 찾기** (질문 3~4개, 브라우저 안에서만 계산, 저장 안 함, 결과는 「조건에 맞는 곳」 목록, 「좋은 순」 없음)
- 로컬 손님: 동네 → 업종 → 중요한 것(가까운 곳 많음 / 오래된 브랜드 / 본부 처분 이력 없음)
- 로컬 창업자: 예산 → 업종 → 원하는 것(매장 늘어나는 중 / 닫는 비율 낮음 / 업력 5년 이상)
- **온라인 손님**: 무엇을 하려나요(음식 시키기·물건 사기·중고 팔기·숙소·일 맡기기·일자리·집 구하기·결제) → 중요한 것(멤버십 없이 무료 / 동네 직거래 / 해외 직구 포함 / 처분 이력 확인하고 싶음) → 해당 분야 카드 목록 + 「고를 때 볼 것」
- **온라인 사장님**: 무엇을 하나요(음식점·쇼핑몰·숙박·전문 서비스·구인) → 사업자 있음/없음 → 중요한 것(수수료 구조가 단순 / 정산 빠른 편(공식 표기 기준) / 광고 없이 시작 가능) → 조건에 맞는 카드 + 「비교에 담기」
- **비교 화면** `/brand/compare/?ids=…`: 최대 4개, noindex.
