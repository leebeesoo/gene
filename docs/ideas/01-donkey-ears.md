하자 — 「속마음 칠판」(최종 이름, 2026-11-13 사장님 확정 · 가칭 「임금님귀는 당나귀귀」)은 Cloudflare Durable Objects 무료로 만든다(우리 서버 없음, 저장 없음, 하루 약 5만 명 방문까지 0원). 칠판 화면에는 광고를 넣지 않는다.

## 1. 최종안 요약

- **무엇**: `/donkey/` 「속마음 칠판」(가칭 「임금님귀는 당나귀귀」에서 확정). 누가 한 줄 쓰면 **지금 접속한 모두의 칠판** 아무 곳에 쪽지처럼 붙었다가(겹칠 수 있음, ±3° 기울기) 20초~1분 뒤 사라짐. 화면에 **PC 36개·태블릿 24개·폰 16개**까지, 넘치면 오래된 것부터 사라짐. 글은 어디에도 저장하지 않고 **방송만** 함.
- **칠판 위 안내**: 「속마음을 적어 보세요. 잠깐 보였다 사라져요」 + 「어디에도 저장하지 않아요. 다만 보는 사람이 캡처할 수는 있어요.」 (「완전히 사라짐」은 약속하지 않음)
- **어떻게**: 정적 화면(Cloudflare Pages) + Cloudflare **Durable Objects(DO)** 하나가 「중계소」 역할. 같은 Cloudflare 계정, 무료 플랜.
- **안전**: 100자 제한, 10초에 1번, 금칙어는 **중계소에서** 걸러서(화면만 거르면 우회됨) 방송, 링크·전화번호 차단, 신고 3번이면 모두에게서 숨김, 자해 단어엔 109 안내, 봇 막기(Turnstile 무료).
- **한도 넘으면**: 칠판이 꺼지고 자동으로 「혼자 외치고 사라지기」 모드로 바뀜(오류 화면 없음). 다음 날 오전 9시(한국)에 자동 복구.
- **돈·검색**: 칠판 자체는 검색·광고 둘 다 기대 안 함. 「이야기·사용법」 페이지 1쪽에만 광고. 허브의 재미·재방문 미끼.
- **기존 안(비밀 쪽지 링크)**: 이번 범위에서 뺌. 칠판 반응을 본 뒤 2단계 후보.

### 다시 계산 (2026-11-13, 화면 글 수 늘린 뒤)

화면에 띄우는 쪽지 수(폰 16·PC 36)는 **각자의 화면에서만** 정하는 값이라 중계소 메시지 양을 바꾸지 않는다. 요금에 세는 것은 **받는** 메시지(글·신고·ping)뿐이고, 모두에게 **보내는** 방송은 몇 명이든 무료.

| 항목 | 방문 1번당 | 근거 |
|---|---|---|
| Worker 요청(입구) | 1 + 재접속 0.3 = **1.3** | 접속 1번 = 1요청 |
| DO 요청 — 접속 | 1 + 재접속 0.3 = 1.3 | 입구가 방으로 넘길 때 1요청 |
| DO 요청 — 받은 메시지 | (글 3 + 신고 1 + ping 약 6) ÷ 20 = **0.5** | 받은 WebSocket 메시지 20개 = 요청 1. ping은 45초마다, 평균 5분 머문다고 가정. ping 자동 응답이 세이는지는 **미확인**이라 최악으로 넣음 |
| **DO 합계** | **약 1.8** | 하루 10만 ÷ 1.8 ≈ **5.5만 명** |
| Worker 합계 | 약 1.3 | 하루 10만 ÷ 1.3 ≈ 7.7만 명 → DO 쪽이 먼저 참 |

- 쪽지가 많이 보이면 사람들이 조금 더 쓸 수는 있다. 글을 방문당 3개→6개로 두 배 잡아도 DO 합계 1.95 → **약 5.1만 명**. 결론은 그대로 「하루 약 5만 명」.
- 화면을 PC 36개로 채우려면 칠판 전체에 초당 약 1개(쪽지 평균 30초)가 필요 → 하루 약 8.6만 글 = DO 요청 약 4,300. 한도의 4%.
- 최악(방 전체 상한 초당 5개를 하루 종일): 43만 글 = DO 요청 약 2.2만. 봇은 Turnstile이 먼저 막음.
- 실행시간: 잠자기 기능 + 알람 없음. 방이 하루 종일 깨어 있어도 10,800 GB-s < 13,000 → 쪽지 수와 상관없이 안전.

## 3. 선택과 이유

**추천: Cloudflare Durable Objects (방 1개, 잠자기 기능 사용)**
1. **중계소에서 거른다** — 모든 글이 DO를 지나므로 금칙어·도배·링크 차단·신고 집계를 우리 코드가 강제함. 화면 코드를 고쳐서 우회해도 소용없음. 이게 운영자 책임을 지키는 핵심.
2. **한도가 가장 넉넉함** — 동시 접속 상한이 사실상 없고(Supabase 200, Firebase 100), 보내는 메시지는 공짜라 사람이 많아도 글 1개 비용이 그대로.
3. **꺼지지 않음** — Supabase처럼 1주일 조용하면 멈추는 규칙이 없음.
4. **계정 하나** — 사이트(Pages)·도메인·봇 막기(Turnstile)가 모두 같은 Cloudflare 계정. 새 가입 없음.
5. **저장 0** — 글은 메모리에서 방송 후 버림. 디스크(SQLite)엔 아무것도 안 씀.

**대안(DO가 막힐 때): Supabase Realtime 방송** — 동시 200명, 금칙어는 화면에서만 거르므로 약함. 그래서 대안으로만 둠.
**마지막 안전망**: 어떤 서비스든 한도·장애 때는 「혼자 외치고 사라지기」(서버 0)로 자동 전환.

## 5. 운영 규칙·법

**저장을 안 해도 우리는 운영자다.** 남의 글을 우리 도메인 화면에 방송하므로 정보통신망법상 정보통신서비스 제공자에 해당한다고 보고 준비한다.
- **임시조치(제44조의2)**: 권리 침해 신고를 받을 연락처가 필요. 다만 글이 최대 1분 뒤 사라지고 기록이 없으므로 「신고 즉시 해당 글은 이미 사라졌고, 저장된 내용이 없다」가 정직한 답. 반복 피해면 금칙어·차단 강화로 대응.
- **자살예방법**: 자살유발정보는 불법정보 → 위 4절의 차단·109 안내로 대응. 복지부 시행령 개정(삭제·보고 의무) 적용 대상인지는 **미확인**.
- **개인정보**: 글·닉네임·계정 없음. IP는 도배·차단 판단에만 메모리에서 쓰고 24시간 안에 버림, Turnstile은 Cloudflare가 처리 → 개인정보처리방침에 3줄 추가.
- **수사기관 요청**: 줄 것이 없음(저장 0). 처리방침에 그대로 적음.

**꼭 필요한 글 2개 (짧게, `donkey/rules.html` 한 쪽)**
1. **이용규칙**: 금지 — 욕설·성적 표현·혐오, 실명·연락처 등 남의 개인정보, 광고·링크, 자해 방법·동반 모집, 범죄. 어기면 글 숨김·24시간 쓰기 금지. 글은 저장되지 않고, 캡처는 막을 수 없음.
2. **신고 처리**: 글마다 신고 버튼(3명이면 모두에게서 숨김). 그 밖의 권리 침해·문의는 이메일(사장님 문의 이메일), 3일 안에 답. 도움이 필요하면 109·청소년 1388.

**광고: 칠판 화면에는 0칸.** 애드센스는 이용자 글도 게시자가 정책을 지켜야 하고, 지키기 어려우면 그 페이지에 광고를 넣지 말라고 함([AdSense UGC 도움말](https://support.google.com/adsense/answer/11035658)). 실시간으로 바뀌는 글은 미리 검사할 수 없으니 한 번 나쁜 글이 광고 옆에 뜨면 **도메인 전체 승인**이 위험. 광고는 `/donkey/about.html`(이야기·사용법 글) 1칸에만.

## 6. 첫 버전 범위

경로 `/donkey/`(가칭). 중계소 주소는 같은 도메인 `/donkey/live`(Worker 경로). Pages와 같은 도메인에서 경로가 잘 갈리는지는 **출시 전 실측**, 안 되면 `*.workers.dev` 주소로 대신(화면 주소는 그대로).

```
donkey/
  index.html       # 칠판 + 쓰기 칸 + 지금 N명 + 아래 설명 문단, 칠판엔 광고 없음, 짧은 링크 줄만
  css/style.css    # 포인트 색 겨자 #8F6200 / 다크 #D8AE52
  js/config.js     # 중계소 주소·Turnstile 사이트 키 (자리표시면 혼자 외치기만)
  js/filter.js     # 금칙어·링크·전화·자해 검사 + 도배 검사 + 표시 시간 (화면·중계소가 같은 파일)
  js/app.js        # 접속·재접속, 쪽지 무작위 배치·겹침·맨 앞으로, 사라짐, 신고, 혼자 모드, 109 카드
  about.html       # 이야기·사용법·「무엇이 남고 안 남나」 (광고 1칸, 검색용)
  rules.html       # 이용규칙·신고 처리
  privacy.html     # 개인정보처리방침
  og.png
  tests/filter.test.mjs   # node --test
workers/donkey-live/
  src/index.js     # Worker 입구(비상 정지·출처·Turnstile) + DO 「Board」(잠자기 기능)
  src/room.js      # 방 규칙(순수 함수, node로 시험)
  test/room.test.js
  wrangler.toml    # SQLite형 DO 등록, BOARD_OPEN 등 설정값(자리표시)
  README.md        # 사장님 배포 순서
.github/workflows/donkey-live.yml  # 수동 실행 배포(사장님이 넣은 토큰 사용)
```
공용 `common/footer.*` 그대로, 개인정보처리방침 3줄 추가. 허브 카드는 사장님 OK 후.

**예상 작업 시간**: 화면 1.5일 + 중계소 1일 + 금칙어 목록·테스트 1일 + 폰 실측 0.5일 = **약 4일**. 금칙어 목록은 공개 목록을 참고하되 라이선스 확인 후 우리가 다시 정리.

출시 전 확인: 폰 2대로 동시에 써서 뜨고 사라지는지, 일부러 금칙어 변형·링크 넣어 막히는지, 한도 초과를 흉내 내 혼자 모드로 바뀌는지, Cloudflare 대시보드에서 요청 수가 계산과 맞는지(접속 1번≈1.5).
