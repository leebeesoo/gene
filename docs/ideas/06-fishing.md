결론: 공공데이터만으로 가능. 이름 1순위 「물때명당」(/fish/), 후보 「입질지도」「포구수첩」. 공개는 애드센스 승인 뒤(포인트 페이지 50~60쪽이 매일 바뀌는 자동 페이지라 심사 위험). Claude 작업 약 1.5~2주.

오늘 바다낚시지수·물때(고·저조) → 잡히는 어종 → 그 어종의 금어기·금지체장(법령 원문 링크) → 근처 낚시금지·출입통제 구역(「들어가지 마세요」로만 표시) → 이 항구에 신고된 낚시어선 목록(신고 기준, 영업·연락처는 직접 확인) → 낚시방은 카카오·네이버 「○○항 낚시」 검색 링크.
