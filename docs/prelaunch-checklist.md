하나씩 확인하고 결과를 Claude에게 알려 주면 반영한다. 틀린 값은 고치고, 확인된 값은 「확인됨」으로 바꾼다.

## 1. 속마음 칠판 `/donkey/` — 실시간 기능 켜기 (약 20분)
지금은 실시간 연결 없이 「혼자 외치기」 모드로만 돈다. 아래를 마치면 다른 사람 글이 보인다. 자세한 순서: `workers/donkey-live/README.md`

1. **Cloudflare Turnstile 위젯 만들기** — Cloudflare 대시보드 → Turnstile → 위젯 추가(도메인 입력). 「사이트 키」는 Claude에게, 「비밀 키」는 다음 단계에 쓴다.
2. **Cloudflare 비밀값 2개** — `TURNSTILE_SECRET`(위 비밀 키), `IP_SALT`(아무 긴 문자열)
3. **GitHub Secrets 2개** — 저장소 Settings → Secrets and variables → Actions: `CLOUDFLARE_API_TOKEN`(Workers 편집 권한 토큰), `CLOUDFLARE_ACCOUNT_ID`
4. **배포 실행** — GitHub → Actions → 「donkey-live 배포」 → Run workflow
5. **Claude에게 전달** — 중계소 주소(배포 결과에 나옴), Turnstile 사이트 키, 신고 받을 문의 이메일
6. **출시 첫 주** — 하루 5분, Cloudflare 대시보드에서 요청 수 확인(무료 한도 하루 10만)

## 3. 내 미래 머니 `/money/` — 확인 끝 (2026-11-14, 공개 자료로)
사장님이 따로 열어 볼 것 없음. 막혔던 원문은 관보·금융위·예금보험공사·청약홈·법제처 생활법령으로 대신 확인했다. 자세한 주소·날짜는 `money/SOURCES.md`.

1. **청약 점수표** — 그대로(32·35·17 = 84점). 국가법령정보센터는 11-14 점검으로 닫혀 있어 전자관보로 대조: 2024-12-18 뒤 개정령(마지막 2026-06-15 제1592호)은 별표1을 안 고침.
2. **30세 이상 자녀 1년 → 3년** — 2026-04-30 입법예고만 됐고 11-13자 관보까지 공포 안 됨. 계산은 그대로, 화면 문구를 「지금은 1년 기준」으로 고침. 공포되면 문구만 바꾸면 됨.
3. **청약홈 대조** — 무주택 10년·부양가족 3명·통장 15년 → 청약홈도 59점, 「30세 미만 미혼 0점」도 같은 처리. 대조 중 찾은 **미성년 가입기간 인정 규칙**(2024년 전 최대 2년·합쳐 최대 5년)을 청약홈과 같게 계산기에 넣음(테스트 19개 통과).
4. **예금자보호** — 1억 원(2025-09-01), 상호금융도 각 중앙회가 1억 원, 금융기관별 계산: 금융위 보도자료·Q&A와 예보 화면으로 확인. 「금고·조합마다 따로」는 원칙에서 추론한 값이라 화면엔 「그렇게 봐요, 헷갈리면 중앙회에 확인」으로 씀. 주택청약종합저축은 비보호(주택도시기금, 정부 관리) — 옛 이름 「국민주택기금」 고침.
5. **사기** — 112·1332·지급정지 방법(3영업일 안 서면)은 금감원 원문으로 확인. 경찰청 피싱 신고 **1394**(2026-02-01부터)를 상담 안내에 더함. 중고거래 제외(특별법 제2조제2호 단서), 통장 대여 처벌(5년 이하·3천만 원 이하), 1397 확인. 사기 유형 9쪽 출처를 금감원 소비자경보·법제처 원문 주소로 바꿈.
