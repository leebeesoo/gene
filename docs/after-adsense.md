# 애드센스 승인 뒤에 할 일 (2026-11-13 작성)

대화를 지운 뒤에도 이 파일을 보면 된다. 승인 메일을 받으면 위에서부터 진행한다.
원칙: 완성되고 출처를 확인한 것만 공개한다. 아래 목록은 **대량으로 만드는 페이지**이거나 **검증이 더 필요한 돈 계산**이라서 승인 뒤로 미뤘다.

## 승인 직후 (Claude)
1. 광고 단위 ID 3개를 사장님께 받아 전 파일의 `ca-pub-XXXXXXXXXXXXXXXX`, `data-ad-slot="0000000000"`, 루트 `ads.txt`를 교체한다. (`docs/adsense-setup.md`)
2. 자동 광고 설정 확인. 당나귀귀 칠판 화면(`/donkey/` 첫 화면)에는 광고를 넣지 않는다. 사용자가 쓴 글 옆에 광고가 붙으면 애드센스 규정상 위험하다.
