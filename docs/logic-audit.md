## 2. 제철식당 `/sikdang/`

**🔴 식당보다 재료가 먼저 나와요** (사장님 지적 그대로)
- 홈 「전국에서 지금 제철」 카드가 굴·콩·미꾸라지·표고버섯·사과·메밀·쌀 같은 재료예요. 지역 화면 「지금 제철」도 갈치·굴·삼치·돌산갓 같은 재료 카드예요. 정작 「굴구이」·「갈치조림」 같은 요리는 맨 아래 「대표 음식」에 묻혀 있어요. 위치: `js/views/home.js`, `js/views/region.js`, `js/data.js`(seasonalNational/seasonalIn), `js/components.js` foodCard.
- 식당이 없는 화면이 많아요. 지역별 이달 제철 364건 중 204건이 식당 0곳이고, 이달 제철이 전부 식당 0곳인 지역도 45곳이에요(광양·평창·밀양·담양 등). 음식 496종 가운데 203종은 식당이 한 곳도 없어요. 예를 들어 평창을 고르면 홈에 「꼭 먹을 제철 음식: 사과」가 뜨고, 누르면 「사과 내는 집 0곳」이 나와요. 송어회·황태구이 집은 있는데도요. `home.js`의 `showRegion`이 `!f.nr` 항목도 넣어요.
- 권고: 카드 단위를 '요리 + 식당 수'로 바꾸세요(예: 「여수 굴구이 · 5곳」). 식당이 0곳인 항목은 홈·지역 '지금 제철'에서 빼세요.

**🔴 연결이 틀려요** (제철장보기 → `../sikdang/#/food/<이름>`, 62종을 브라우저로 확인)
- 과메기 → **메기**, 냉이 → **고추냉이**, 양배추 → **배추**로 갑니다. `food.js` `resolveFood`의 부분 일치 때문이에요. 검색 「양배추」도 배추만 보여 줘요.
- 브로콜리·감귤은 검색 화면으로 빠지고, 무·양파·대파·당근·감·단감·유자·수박 등은 「식당 찾는 중」에서 끝나요. 「이 재료로 하는 식당」 링크는 식당이 있는 품목에만 달아 주세요.

**🟡 초안 데이터 표시**
- 식당 3,778곳이 **모두** 초안이에요(`data/meta.json` drafts=3778, `config.js` PUBLISH_DRAFTS:true). 그래서 모든 카드에 「검수 중」이 붙어요. 그런데 머리에는 「협찬 없음 · 정부 영업 명단으로 확인」, 홈에는 「영업 중으로 확인한 곳만 올려요」라고 써서 서로 부딪혀요. 카드마다 다는 대신 목록 위에 한 줄(「영업 명단과 자동 대조, 운영자 확인 전」)로 바꾸는 게 좋아요.
- 「문 닫았어요 / 이 메뉴 없어요」 버튼이 식당마다 「준비 중」으로 잠겨 있어요(REPORT_FORM_URL 비어 있음). `contact.html`은 「누르면 … 양식이 열려요」라고 하고 문의 양식도 준비 중이라 연락할 길이 없어요.
- 근거 문장이 메뉴와 안 맞아요. 「굴구이 먹을 수 있는 식당(메뉴: 굴국밥)」처럼 나와요.

**🟡 이름 바꾼 흔적**
- 조사가 「제철한끼가/는」 시절 그대로예요: 「제철식당가 조사한」(`js/views/region.js:44`), 「제철식당는」(`index.html:63`, `about.html:44,61`), 「제철식당가」(`about.html:7,49`). '제철한끼' 글자 자체는 남아 있지 않아요. ⚪ `season/js/app.js:18`의 변수 이름 `HANKI`.
- ⚪ 시·도 이름이 「전남광주통합특별시」라서 다른 사이트의 「전남」과 달라요.
