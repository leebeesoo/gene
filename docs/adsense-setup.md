# 구글 애드센스 붙이는 순서 (사장님용)

사이트에 광고를 띄워 돈을 버는 건 **구글 애드센스(AdSense)** 입니다. (구글 애즈 Ads는 광고를 "사는" 쪽이라 다릅니다.)
승인은 보통 며칠~몇 주 걸리고, 사이트가 공개되어 있고 내용이 충분해야 통과합니다.

## 0. 먼저 끝나 있어야 하는 것
- 도메인을 사서 Cloudflare Pages에 연결 (`DEPLOY.md`)
- PR 머지 → 사이트가 `https://내도메인/` 에서 열림
- 문의 이메일 정하기 (개인정보처리방침·연락처에 들어감)

## 1. 애드센스 가입
1. https://adsense.google.com 접속 → 구글 계정으로 로그인 → 「시작하기」
2. 사이트 URL에 **도메인만** 입력 (예: `jaemilab.com`, `/lotto/` 같은 경로는 넣지 않음 — 도메인 하나로 10개 서비스가 모두 포함됩니다)
3. 국가: 대한민국, 결제 정보(이름·주소)는 나중에 우편 PIN 확인에 쓰이므로 실제 주소로 입력

## 2. 게시자 ID 받기
- 가입하면 `ca-pub-` 로 시작하는 16자리 번호가 나옵니다 (계정 → 계정 정보 → 게시자 ID).
- **이 번호를 저에게 알려주시면** 모든 사이트의 `ca-pub-XXXXXXXXXXXXXXXX`와 루트 `ads.txt`를 한 번에 바꿔 드립니다.

## 3. 사이트 소유 확인
- 애드센스 화면 「사이트」 → 내 도메인 → 「확인」 방법 중 **ads.txt 스니펫** 또는 **애드센스 코드 스니펫** 선택.
- 우리 사이트는 이미 모든 페이지에 애드센스 코드가 들어 있고 `ads.txt`도 루트에 있어서, 2번에서 ID만 바꾸면 확인이 됩니다.
- 확인 후 「검토 요청」을 누르면 심사가 시작됩니다.

## 4. 심사 기다리는 동안
- 사이트를 자주 바꾸지 말고 그대로 둡니다. 빈 페이지·준비 중 화면이 많으면 거절될 수 있습니다.
- 거절되면 이유(예: 콘텐츠 부족)가 나옵니다. 알려주시면 고칩니다.

## 5. 승인 후: 광고 단위 만들기
애드센스 → 광고 → 「광고 단위 기준」 → 아래 3종류를 만들고, 각각의 **광고 단위 ID(10자리 숫자)** 를 알려주세요. 사이트의 `data-ad-slot="0000000000"`에 넣습니다.
- 디스플레이 광고 1개 (반응형)
- 인피드 광고 1개 (목록 사이)
- 멀티플렉스 광고 1개 (페이지 끝 "관련 콘텐츠")
(사이트마다 따로 만들 필요는 없습니다. 같은 ID를 여러 곳에 써도 됩니다. 나중에 수익을 서비스별로 보고 싶으면 서비스별로 만들어도 됩니다.)

## 6. 자동 광고 설정 (애드센스 화면에서 켜기)
애드센스 → 광고 → 사이트 옆 연필 아이콘(수정):
- **자동 광고: 켜기**
- **앵커 광고(화면 아래 고정): 켜기** — 모바일만
- **사이드 레일: 켜기** — 데스크톱
- **전면 광고(비넷): 켜기, 빈도 가장 낮게** — 페이지를 이동할 때마다 뜨는 광고. 테스트형 서비스(근본 테스트·식구궁합·남은봄·나때연감)는 처음엔 「URL 제외」로 빼는 것을 권합니다(문항 진행 중 뜨면 이탈이 큼).
- **페이지 내 자동 광고: 끄기** — 우리가 정해 둔 자리만 쓰기 위해
- 「URL 그룹」에서 서비스별로 다르게 설정할 수 있습니다.

## 7. 결제 받기
- 수익이 1만 원 정도 쌓이면 구글이 집으로 **PIN 우편**을 보냅니다 → 애드센스에 입력
- 수익이 약 10만 원(US$100)을 넘으면 매달 21일 전후 통장으로 들어옵니다 → 「결제」에서 은행 계좌 등록(영문 은행명·SWIFT 코드 필요)
- 세금 정보(한국 거주자)도 「결제 → 설정」에서 입력

## 하지 말아야 할 것 (계정 정지 사유)
- 내 광고를 내가 누르기, 지인에게 눌러 달라고 하기
- "광고를 눌러 주세요" 같은 문구
- 광고를 버튼 바로 옆에 붙이기 (우리 사이트는 띄워 두었습니다)
