## 1. 진단: 지금 화면이 왜 클릭하고 싶지 않은가

캡처는 390×844와 1280×800, 라이트·다크로 찍었다.

**허브**
- 설정 화면처럼 보인다. 10개 서비스가 모두 같은 형식의 줄(점 + 이름 + 설명 + 꺾쇠)이라 눈이 머물 곳이 없다.
- 서비스를 구분하는 표시가 6px짜리 색 점 하나뿐이다. 무엇을 하는 서비스인지, 결과가 어떻게 나오는지 미리 보여 주는 장치가 없다.
- 첫 문구 "오늘 뭐 해볼까?"는 어느 사이트에 붙여도 되는 일반 문장이다. 날마다 바뀌는 내용도 없어서 다시 올 이유가 없다.
- 데스크톱에서는 길이가 다른 세 열 때문에 아래쪽에 빈 공간이 생기고, 첫 화면 하단을 빈 광고 상자가 차지한다.

**서비스 공통으로 남은 'AI 느낌'**
- 7개 서비스가 같은 틀이다. 작은 머리말, 굵은 두 줄 제목(한 단어만 포인트 색), 회색 설명, 흰 폼 카드, 꽉 찬 버튼 순서다. 결과보다 입력 칸이 먼저 보인다.
- 제목의 한 단어만 색칠하는 방식("전국에 **몇 명**", "**몇 번**", "**어떤 세상**")은 AI 랜딩 페이지의 전형이다.
- 다크 모드에서 채도 높은 포인트 색(#FF5C41, #E07A97, #7A93F0, #6DB08C)으로 큰 버튼을 꽉 채운다. 검은 바탕에서는 이것이 그대로 네온으로 보인다.
- 네모 안에 아이콘을 넣은 로고, 모든 것을 칩으로 처리하는 방식, 같은 Pretendard 700 제목 때문에 10개 서비스가 한 템플릿처럼 보인다.

## 3. 공통 규칙 (DESIGN.md를 대체·보완)

1. **첫 화면은 결과부터 보여 준다.** 폼 카드로 시작하지 않는다. 예시 결과나 오늘의 결과를 먼저 보여 주고, 입력은 그 아래나 시트에 둔다.
2. **서비스마다 첫 화면 시각물 1개를 허용한다.** SVG, 데이터 시각화, 큰 글자 중 하나다. 이 시각물에 한해 서비스 바탕색을 화면 폭 전체로 깔 수 있다.
3. **첫 화면 큰 글자를 허용한다.** 페이지당 1개, `clamp(36px, 10vw, 88px)`. 나머지 글자 크기 단계(28/20/16/14/12)는 그대로다.
4. **글꼴은 서비스당 2종까지.** 본문은 Pretendard로 고정하고, 제목용 글꼴 1종을 Google Fonts에서 고른다. 글자 수가 적은 제목용 글꼴은 `&text=` 파라미터로 필요한 글자만 받아 용량을 줄인다.
5. **다크 모드 포인트 색 규칙**
   - OKLCH 기준으로 채도(C) 0.12 이하, 밝기(L) 0.68–0.76.
   - 다크 모드의 주 버튼은 포인트 색으로 채우지 않는다. **밝은 잉크색으로 채우고 글자는 바탕색**으로 쓴다. 포인트 색은 숫자, 선택 테두리, 데이터에만 쓴다.
6. **제목에서 한 단어만 색칠하는 처리는 금지.** 강조가 필요하면 굵기나 크기로 한다.
7. **네모 안 아이콘 로고는 금지.** 서비스 이름은 그 서비스의 제목용 글꼴로 쓴 글자 로고로 한다.
8. 광고는 첫 화면 아래에만 두고, 광고가 로드되지 않으면 영역 높이를 0으로 접는다.
9. 움직임은 서비스당 1개만 둔다. 400ms 이하, 화면에 들어올 때 1회만 재생한다. `prefers-reduced-motion`이면 최종 상태만 보여 준다.
10. 그림자와 테두리 규칙은 DESIGN.md를 유지한다. 허브 타일에 한해 반경 16px을 허용한다.

## 5. 허브 재설계: "오늘의 재미판"

- **머리:** 날짜 한 줄("11월 12일 목요일")과 재미랩 글자 로고만 둔다. 첫 화면을 차지하던 큰 제목은 없앤다.

  - 모바일: 2열, 간격 8px. 첫 타일(오늘로또)은 2열을 다 쓰는 와이드다. 나머지는 1×1이고, 그 사이에 와이드 1개를 더 넣는다.
  - 데스크톱: 4열 벤토. 와이드 2개, 세로형 1개.
- **타일 구성:** 각 타일은 그 서비스의 bg색, 제목용 글꼴, **살아 있는 미리보기**를 쓴다. 타일 전체를 링크로 만든다.

| 서비스 | 타일 미리보기 |
|---|---|
| 오늘로또 | 날짜 시드로 뽑은 오늘의 공 6개, 추첨까지 남은 시간 |
| 명당로드 | 작은 한국 지도 실루엣, 1등 최다 지점 1곳 |
| 맛남의 광장 | "오늘 남는 것" 1위 품목과 변동 % |
| 제철장보기 | "11월"과 품목 3개 |
| 제철식당 | 이달 음식 이름 하나(세리프) |
| 근본 테스트 | 인주 도장 "根"과 "16가지 코드" |
| 식구궁합 | 작은 오각형 |
| 이름레이더 | 돌아가며 바뀌는 이름과 "전국 ○명" |
| 남은봄 | 12×8 미니 격자 |
| 나때연감 | 랜덤 연도 "1988"과 그해 노래 제목 |

- **카테고리:** 섹션 제목 없이 타일 왼쪽 위에 작은 라벨(운세·데이터·먹거리)만 단다. 상단 탭으로 거르게 한다.
- **움직임:** 타일이 화면에 들어올 때 미리보기만 1회 재생한다. 모션 줄이기 설정이면 정지 상태로 둔다.
- **데이터와 예비 문구:** 미리보기 데이터는 각 서비스의 JSON을 지연 로드한다. 로드에 실패하면 정적 예비 문구를 보여 준다.
- **다크 모드:** 타일 bg는 각 서비스 다크 bg, 테두리는 1px 선으로 처리한다.
