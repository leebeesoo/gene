# 명당로드 — 데이터 출처

**데이터 스냅샷: 2026-11-05 (KST)** · 로또 6/45 **1~1248회**(2026-10-31 추첨분) 기준

## 1. 당첨번호 (`data/draws.js`)

- 출처: 동행복권 당첨결과 화면(<https://www.dhlottery.co.kr/lt645/result>)이 쓰는 JSON 엔드포인트
  `GET /lt645/selectPstLt645InfoNew.do?srchDir=center&srchLtEpsd=<회차>` (한 번에 약 10회차)
- 범위: 1회(2002-12-07) ~ 1248회(2026-10-31), 1248회 전부
- 필드: 회차, 추첨일, 본번호 6개, 보너스, 1등 당첨자 수, 1등 1인당 당첨금
- 2025년 사이트 개편 이후 예전 `common.do?method=getLottoNumber` API는 메인 페이지로 리다이렉트되어 쓸 수 없었습니다.

## 2. 1등 배출 판매점 (`data/stores.js`)

- 출처: 동행복권 당첨판매점 화면(<https://www.dhlottery.co.kr/wnprchsplcsrch/home>)이 쓰는 JSON 엔드포인트
  `GET /wnprchsplcsrch/selectLtWnShp.do?srchWnShpRnk=1&srchLtEpsd=<회차>&srchShpLctn=`
- 범위: **262회(2007-12-29) ~ 1248회**. 동행복권은 262회부터 판매점 정보를 공개합니다(1~261회는 비공개라 수록하지 않음).
- 수록 규모: 판매점 **4,615곳**, 판매점 1등 **9,217건** + 인터넷 구매 1등 **134건**. 회차별 합계가 공식 1등 당첨자 수(`rnk1WnNope`)와 987개 회차 모두 일치함을 확인했습니다(1등 없는 289·295·463회 포함).
- 회차별 1등 판매점 목록을 모두 받은 뒤, 동행복권 판매점 ID(`ltShpId`) 기준으로 묶어 판매점별 1등 건수를 셉니다.
  - 같은 회차에 한 판매점에서 1등이 여러 장 나오면 응답에 여러 줄로 나오며 각각 1건으로 셉니다.
  - 자동/수동/반자동 구분, 영업 상태(정상/폐점), 공개 좌표(위·경도), ‘당첨 당시 상호’를 함께 보관합니다.
  - 인터넷 구매(동행복권 사이트) 1등은 지도·순위에서 빼고 회차별 건수만 따로 셉니다.
- 지역: 주소 첫 단어로 시·도를 정합니다. 2026-07 출범한 **전남광주통합특별시** 주소(`전남광주 …`)는
  광주 5개 구(동·서·남·북·광산구)면 광주, 나머지는 전남으로 나눠 기존 17개 시·도 지도에 표시합니다.
- 주소: 현재 도로명 주소(`shpAddr`)를 쓰고, 비어 있거나 깨진 옛 데이터는 당첨 당시 주소(`befAddr`)를 씁니다.
- ‘역대 최다 배출 명당’ 순위는 뉴스 기사 수치가 아니라 위 공식 회차별 자료를 직접 센 값입니다. 기사 속 횟수는
  1~261회 포함 여부·집계 시점이 달라 차이가 날 수 있습니다.

## 3. 지도 경계 (`data/geo.js`)

- 출처: [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps) `kostat/2013/json/skorea_provinces_geo_simple.json`
  (통계청 2013 행정경계 단순화본)
- 등장방형 투영(위도 36° 보정) 후 Douglas–Peucker로 단순화해 SVG 경로로 바꿨습니다. 작은 섬(울릉도 등)은 생략했습니다.
  이후의 경계 변경(2023 군위군 대구 편입, 2026 전남광주 통합 등)은 반영하지 않은 모양입니다.

## 갱신 방법

```bash
# Node 18+ (프록시 환경이면 NODE_USE_ENV_PROXY=1, Node 22.21+)
node tools/update-data.mjs              # 최신 회차까지 다시 받기 (캐시 재사용, 최근 3회는 항상 새로)
node tools/update-data.mjs --from=1240  # 1240회부터 판매점 다시 받기
node tools/update-data.mjs --offline    # 캐시만으로 data/*.js 재생성
```

- 동행복권은 짧은 시간에 요청이 몰리면 연결을 끊습니다. 스크립트는 요청 간격(기본 900ms)과 지수 백오프 재시도를 둡니다.
- 엔드포인트는 공식 문서화된 API가 아니며 사이트 개편 때 바뀔 수 있습니다.
