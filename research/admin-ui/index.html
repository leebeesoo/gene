홈서비스 관리자 레퍼런스

국내외 플랫폼의 운영자·파트너·가맹점 화면을 공식 가이드, 제품 페이지, 앱스토어, 공개 데모에서 모았습니다. 홈서비스 중개(요청 → 매칭 → 방문 → 정산 → CS)에 맞는지 기준으로 정리했습니다. 카드를 누르면 원본 크기와 출처가 열립니다.

우리 관리자에 가져올 패턴

여러 플랫폼에서 반복해서 보인 구조만 골랐습니다. 썸네일을 누르면 해당 화면이 열립니다.

화면을 두 갈래로 나누기

모은 화면을 보면 운영자용은 PC 웹, 파트너용은 모바일 앱이 표준입니다. 같은 데이터를 두 형태로 보여주는 구성을 권합니다.

  • 모든 목록은 상태 탭(건수) + 필터 칩 + 일괄 처리 + 엑셀 내보내기
